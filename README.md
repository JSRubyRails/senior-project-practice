## Development Workflow

Branch → Code → Commit → Push → Pull Request → Review → Merge

1. **Branch** — create a feature branch off `main`.
2. **Code** — make the changes on that branch.
3. **Commit** — record the work with a clear message.
4. **Push** — publish the branch to the remote.
5. **Pull Request** — open a PR describing the change.
6. **Review** — address feedback from reviewers.
7. **Merge** — merge the approved PR into `main`.
